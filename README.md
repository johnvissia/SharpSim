# ⚡ SharpSim

A stats-focused MLB simulation platform built to track and find betting value on moneylines and spreads using real market lines and fake coins.

## Features
* **Risk-Free Simulation:** Test strategies with fake coins mapped against real-time sportsbook lines.
* **Data & Feedback:** Stats-focused dashboard designed to give immediate visual feedback on your betting model's edge.
* **Lineup Integration:** Fetches official pre-game batting lineups and probable pitchers from the MLB Stats API.
* **Matchup Splits:** Factors in LHP vs. RHP platoon advantages automatically.

## Tech Stack
* Next.js, TypeScript, and Firebase.
